Install SourceTree on Ubuntu with Wine

These are the steps that worked on Ubuntu 26.04 with Wine 10.0 and SourceTree Enterprise 3.4.33. Expect about 30–40 minutes in total; most of that is the .NET install.

Step 3: Install .NET Framework 4.8 and the Windows fonts

  • This takes 10–20 minutes. It installs .NET 4.0, then 4.5, then 4.8.
  • It can look frozen while it compiles the libraries. That’s normal, so don’t close it.

Check it worked:

Step 4: Download the SourceTree installer

Use the Enterprise .msi installer. The normal SourceTreeSetup.exe usually fails under Wine.

(The newest version is listed at https://www.sourcetreeapp.com/download-archives.)

Step 5: Install SourceTree

An installer window opens:

  1. Accept the license agreement.
  2. Keep the default install folder.
  3. Click Install, then Finish.

Don’t use the silent option /qn. It skips the license screen, so SourceTree never actually gets installed.

The installer adds SourceTree to your app menu. Press Super and type “Sourcetree Enterprise”.

Using SourceTree

  • Opening your projects: your Linux files are on the Z: drive. For example, /home/<you>/projects is Z:\home\<you>\projects.
  • GitHub or Bitbucket accounts: add them in Tools → Options → Authentication, using a personal access token instead of your password.

Problem Fix
sudo: A terminal is required to authenticate Run sudo commands in a real Terminal window, or use pkexec instead of sudo.
Wine environment came out 32-bit Install wine64, delete ~/.wine-sourcetree, and redo Step 2.
